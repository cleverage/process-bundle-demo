## Usage

```bash
make start
```

Then access to UI via http://process-bundle-demo.localhost/process (username: admin@clever-age.com / password: admin@clever-age.com)

## PostgreSQL

The demo runs on MySQL by default. To run it on PostgreSQL, configure it before the first `make start`: see
[running the demo on PostgreSQL](postgresql.md).

## Mocking APIs

See [Mocking APIs with WireMock](wiremock.md): the `wiremock` service and the `demo.wiremock.*` processes.
